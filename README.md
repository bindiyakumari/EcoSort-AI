# EcoSort-AI
EcoSort AI is an intelligent waste-segregation assistant aligned with UN SDG 12 (Target 12.5). Using text or photo inputs, it accurately classifies items into Wet, Dry, Hazardous, or E-Waste streams while providing preparation tips (like rinsing or isolating grease) to prevent recycling contamination at the source.
